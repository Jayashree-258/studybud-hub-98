# Studybud Hub

Prompt: Build “Life Saver” – UG Student Notes Platform
Act as a senior full-stack developer and build Life Saver, a professional, responsive, and production-ready web application that helps undergraduate students access syllabus-based notes.
Core Features:

Student Dashboard: Secure login/register, course and semester selection, subject-wise notes, search, filters, bookmarks, recent notes, and PDF downloads.


Admin Dashboard: Manage users, courses, semesters, subjects, units, topics, notes, PDFs, and important questions. View download statistics and analytics.


Notes System: Provide concise, exam-oriented notes with definitions, key concepts, explanations, examples, important questions, and quick revision summaries.


PDF Generation: Create clean, professional, printable PDFs with a cover page, academic details, structured content, and consistent formatting.


Modern UI: Build a mobile-first interface with professional layouts, reusable components, accessible design, and responsive dashboards.


Backend & APIs: Develop secure, scalable REST APIs with authentication, role-based access, validation, error handling, search, pagination, filtering, and API versioning (/api/v1/).


Database: Use a normalized PostgreSQL database with Prisma ORM to manage users, courses, subjects, notes, PDFs, bookmarks, and downloads.


Security & Performance: Implement password hashing, secure authentication, rate limiting, file validation, environment variables, database indexing, caching, and optimized queries.


Technology Stack: React, TypeScript, Vite, Tailwind CSS, Node.js, Express.js or NestJS, PostgreSQL, and Prisma.


Deployment & Testing: Include sample data, unit/integration tests, Docker configuration, .env.example, API documentation, database schema, and README.

Requirements: Use clean, maintainable code, SOLID principles, reusable components, and a modular architecture. Ensure all features are functional, the frontend and backend are properly integrated, and the APIs can support future mobile applications and integrations.
Final Goal: Deliver a complete, secure, scalable, and deployment-ready Life Saver platform that enables UG students to discover, read, revise, bookmark, and download high-quality academic notes easily. Do not create just a static UI or demo.
